# Submissions

This directory is reserved for contribution records/examples if WindBar chooses to use repository-hosted submissions.

Creators are not required to host their actual project here. Community work may live in the creator's own repository or elsewhere, with this repository linking to it for review/discovery.

A future submission format may record:

- Name
- Creator
- Content type
- Description
- Screenshots
- Source/project link
- Download/release link where appropriate
- License
- WindBar compatibility
- Known limitations
- Official-integration request/status

No submission is automatically endorsed, bundled, or supported by WindBar.
