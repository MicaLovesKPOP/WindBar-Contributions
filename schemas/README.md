# Schemas

This directory is reserved for machine-readable schemas for WindBar creator content.

Potential future schemas include:

- Layout Profiles
- Visual Themes
- Experience Presets
- Plugin manifests

The schemas do not exist yet because the corresponding public contracts have not been finalized. Placeholder schemas should not be added merely to make the repository look complete.

When a schema is introduced, it should document versioning, compatibility, required/optional fields, validation behavior, and migration expectations.
