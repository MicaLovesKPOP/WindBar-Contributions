# Contributing

This repository is the public contribution/creator hub for WindBar.

## Current contribution model

Community creations are external by default. WindBar does not automatically browse, install, endorse, or support everything submitted here.

Creators may:

1. Build and host their work independently.
2. Share it with the community.
3. Submit it here for visibility, feedback, examples, or possible consideration for official integration.

## Before submitting

Read:

- [CREATOR_GUIDE.md](CREATOR_GUIDE.md)
- [CONTENT_TYPES.md](CONTENT_TYPES.md)
- [QUALITY_GUIDELINES.md](QUALITY_GUIDELINES.md)
- [docs/licensing.md](docs/licensing.md)
- [docs/official-adoption.md](docs/official-adoption.md)

## What a submission should include

- Name and content type
- Creator/maintainer
- Description and intended use
- Screenshots or video where useful
- WindBar version/compatibility information
- Source location where applicable
- Declared license
- Installation/testing notes
- Known limitations

Executable/plugin submissions may be held until WindBar has a documented public plugin API and security model.

## No guarantee of integration

Submission does not imply endorsement, inclusion, or a maintenance commitment from WindBar. Official adoption requires a separate review and decision.
