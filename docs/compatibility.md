# Creator Compatibility

WindBar creator formats will use explicit compatibility information once their public contracts are stable.

Creators should expect future packages to declare at least:

- Content/package version
- Minimum/compatible WindBar version range
- Content type
- Required capabilities or dependencies where applicable

Do not assume draft schemas, file names, or plugin concepts are stable until they are explicitly marked as supported public contracts.

WindBar may reject or disable incompatible content rather than attempting unsafe best-effort loading.
