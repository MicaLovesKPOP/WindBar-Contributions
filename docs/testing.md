# Testing Creator Content

Testing expectations will become more specific as WindBar's public content formats stabilize.

For now, creators should test against the WindBar version they claim to support and document known limitations.

Depending on content type, official-integration candidates may be evaluated across:

- Bottom, top, left, and right taskbar placement
- Common scaling values and runtime DPI changes
- Multiple-monitor setups where relevant
- Light/dark and supported visual variants
- Keyboard/focus/accessibility behavior where interactive
- Performance and repeated update behavior
- Safe failure/recovery
- Upgrade compatibility

Executable plugins will be held to a higher testing/security bar than data-only content such as layouts or themes.
